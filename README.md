# Inventory Management REST API

A REST API built with Node.js, Express.js, and SQL for managing products, suppliers, and sales.

## Technologies

- Node.js
- Express.js
- SQL
- Postman

## Features

- Create products
- Retrieve products
- Update products
- Delete products
- Manage suppliers
- Manage sales
- SQL database integration
- RESTful API endpoints

## Database

The project uses a relational SQL database with tables for:

- Suppliers
- Products
- Sales

## API Testing

All API endpoints were tested using Postman.

The database relationships are represented in the ERD diagram included in this repository.
